# Changelog

## 1.0.0

First public release.

- Menu bar app with per-mouse DPI presets, applied automatically when the mouse connects.
- 104 Razer mice supported from OpenRazer's protocol data. The DeathAdder Essential is verified.
- Temporary DPI on wired mice, so the DPI saved in the mouse for other computers isn't changed.
- One-time confirmation for untested, wireless and saved-only models, and Restore Original DPI for saved-only models.
- `dpiswitcher` command-line tool with `list`, `get`, `set`, `report` and `models`.
- No permissions required, universal binary (Apple Silicon and Intel), macOS 13+.
